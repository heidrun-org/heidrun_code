# Web styling rules index

- Created: 22 October 2026
- Last updated: 23 October 2026
- Status: Maintained index for agents and tools
- Related framing: [Project instructions](../../../AGENTS.md)
- Related rules: [Glossary of Heidrun Code](../glossary/index.md)
- Related issue: [issue 796](https://github.com/heidrun-org/heidrun/issues/796), [issue 799](https://github.com/heidrun-org/heidrun/issues/799), [issue 810](https://github.com/heidrun-org/heidrun/issues/810)

This file lists the files of this folder and, for each rule, the test that enforces it; read it before a change to the colors, the buttons, the hover, the spacing, or the icons of the web page, and note that the paths of the tests start at `packages/apps/web_frontend/src`.

- [README.md](README.md): the overview of this folder, for people.
- [shared_design.md](shared_design.md): the shared palette, the buttons and their states, the contrast, the status displays, and the development checks. Tests: the local colors, the purpose variables, the Bootstrap theme, and the contrast in `design/design_rules.test.ts`; the shared look of every button and text field in `design/control_styles.test.ts`; the base rules of a button in `button_rules.test.ts`; the color themes and the hover of an icon button on a menu in `design/theme_palette.test.ts`; the status dots in `status_indicators.test.ts`. Read it before changing an application color, button appearance, or status display.
- [shared_design_inventory.md](shared_design_inventory.md): the design inventory, the justified exceptions for specialized rendering, and the color themes of the Settings window. Tests: the exceptions in `design/design_rules.test.ts`; the color themes in `design/theme_palette.test.ts` and `components/SettingsModal.test.ts`; the selected row of a list group in `design/control_styles.test.ts`.
- [colors_and_scroll_bars.md](colors_and_scroll_bars.md): the colors of the window and the scroll bars. Tests: the values of the colors, the background of the terminal, and the icons of the sidebar icon bars in `theme_colors.test.ts`; the backgrounds of the shell, the sidebars, the panes, and the pane headers in `pane_backgrounds.test.ts`; the scroll bars in `scrollbar_rules.test.ts`.
- [panes_appearance.md](panes_appearance.md): the frames of the window, the borders and the corners of the panes, the move preview of a pane, the pane header, the composition bar, and the file view pane. Tests: `pane_joints.test.ts`, `components/PaneGrid.test.ts`, `components/PaneCard.test.ts`, `pane_backgrounds.test.ts`, `components/CompositionBar.test.ts`, and `components/PushToTalkButton.test.ts`, as each rule of the file says.
- [sidebars_appearance.md](sidebars_appearance.md): the titles of the sidebar sections, the sidebar icon bar, and the Past chats, Code hosting, File explorer, and Needs you sidebar sections. Tests: `sidebar_padding.test.ts`, `components/ToHandlePanel.test.ts`, `bootstrap_parts.test.ts`, `components/ChatReferenceDetails.test.ts`, `components/FilesPanel.test.ts`, and `components/NeedsYouWorkspaces.test.ts`, as each rule of the file says.
- [status_bar_appearance.md](status_bar_appearance.md): the status bar sections, the space after the workspace status bar section, and the Git branch section with its branch picker. Tests: `components/StatusBar.test.ts`, `components/QuotaSummary.test.ts`, `components/WorkspaceStatusSummary.test.ts`, and `status_bar_bootstrap.test.ts`, as each rule of the file says.
- [statistics_and_settings_appearance.md](statistics_and_settings_appearance.md): the colors of the charts of the Statistics window, the size of the inputs of the tab "Work of one person", and the padding of the information card of an option of the Settings window. Tests: `lib/user_activity_workspaces.test.ts`, `components/UserActivityTab.test.ts`, and `components/PersonWorkTab.test.ts`, as each rule of the file says.
- [bootstrap_utility_classes.md](bootstrap_utility_classes.md): the rule to use Bootstrap components, utility classes, and theme variables, and the place of the list of the allowed utility classes. Tests: the list of the utility classes in `bootstrap_parts.test.ts`; the local colors in `design/design_rules.test.ts`.
