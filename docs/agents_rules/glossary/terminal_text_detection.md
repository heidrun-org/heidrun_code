### Text detection

The Settings section for terminal issue and request information cards and ordinary web links.

### Terminal reference

A shorthand number or a full web address for an issue, a GitHub pull request, or a GitLab merge request. Shorthand uses the workspace repository. A full web address names its repository.

### Information card

The details and actions shown when the pointer rests on a terminal reference. The terminal uses the same card content and merge controls as the Code hosting sidebar section.
