This file lists the files of this folder, for agents and tools.

- [README.md](README.md): the overview of this folder, for people.
- [heidrun_names.md](heidrun_names.md): Heidrun Organization, Heidrun Code, Heidrun Notebook, the official name, the identifier, the former name, and the persisted name. Read it each time that you write the name of an application, a package, or a tool.
- [workspaces_tabs_and_panes.md](workspaces_tabs_and_panes.md): the workspace, the workspace folder, the tab, the pane, the file view pane, the diff pane, the front matter, the front matter card, the coding agent, the tab bar, the viewport, the pinned pane, the column of pinned panes, the usage wheel, the dragged pane, the destination pane, the drop triangle, and the move preview.
- [sidebars.md](sidebars.md): the left sidebar, the right sidebar, the sidebar section, the Clipboard, Launchers, Source control, Code hosting, and File explorer sidebar sections, the launcher, and the sidebar icon bar.
- [chats.md](chats.md): the chat, the chat session, the Past chats sidebar section, and the Chats sort dropdown menu.
- [coding_agent_configuration.md](coding_agent_configuration.md): the coding agent configuration, the memory file, the subagent, the skill, and the removed configuration item. Read it when you change the tables `memory_files`, `subagents`, or `skills` of the package `data_layer_coding_agents`.
- [dynamic_topics.md](dynamic_topics.md): the dynamic topic, the raw dynamic topic, the clustered dynamic topic, the translation table, the dynamic topic source information, the dynamic topic extraction, and the dynamic topic bar. Read it when you change the Past chats sidebar section or the dynamic topics.
- [code_hosting.md](code_hosting.md): the search line, the search field, the saved search, and the level of a saved search of the Code hosting sidebar section. Read it when you change the Code hosting sidebar section.
- [status_bar.md](status_bar.md): the status bar, the status bar section, the unspecified Claude quota, the information card, the information card tooltip, and the Workspace status bar section.
- [pane_focus_history.md](pane_focus_history.md): the top bar, the pane focus history, the Back button, and the Forward button. Read it when you change the top bar or the focus of the panes.
- [user_activity.md](user_activity.md): the user activity time, the action, the cool down, the active period, the user activity record, the User activity sidebar section, the Statistics window, the User activity tab, the histogram of the user activity time, and the slot. Read it when you change the detection of the activity of the developer, its sidebar section, or the Statistics window.
- [statistics_charts.md](statistics_charts.md): the chart legend and the chart information card of the charts of the Statistics window. Read it when you add or change a chart of the Statistics window.
- [guards.md](guards.md): the guard, the built-in guard, the project guard, the action, the line, the guard window, the confirmation window, and the Guards section of the Settings window. Read it when you change the guards, the guard window, the confirmation window, or the Guards section.
- [heidrun_code_mobile.md](heidrun_code_mobile.md): Heidrun Code Mobile, the mobile website, the mobile server, the pairing key, the bottom bar, the plain terminal on the phone, the macro button, and the microphone button. Read it when you change the packages `mobile_website` or `mobile_server`.
- [person_work.md](person_work.md): the Work of one person tab, its source, the Git history, the AI cost, the person, the person chooser, the time range of the Work of one person tab, the day, the totals, the average per day, and the bar chart of the work of one person. Read it when you change the tab "Work of one person" of the Statistics window.
- [issue_fix_workflow.md](issue_fix_workflow.md): the Issue Fix Workflow, the Issue Fix Setup, the Issue Fix Implementation, the Issue Fix Review, the Issue Fix Completion, the added request, the related added request, and the unrelated added request. Read it when you change the skill [issue_fix_workflow](../../../.agents/skills/issue_fix_workflow/SKILL.md) or the section "Issue Fix Workflow" of the file [AGENTS.md](../../../AGENTS.md).
- [macros.md](macros.md): the macro, the hard-coded macro, the personal macro, the personal macro file, the project macro, and the command line heidrun_code_ctrl. Read it when you change the macros or the command line `heidrun_code_ctrl`.
- [voice_input.md](voice_input.md): the voice input, the push-to-talk button, the level bars, the Whisper model, the Voice input section of the Settings window, and the word replacement list. Read it when you change the voice input or the package `voice_input`.
- [terminal_text_detection.md](terminal_text_detection.md): the text detection, the detection family, the rule of the text detection, the precedence, the hover buttons, and the Try a text field. Read it when you change the detection of the web addresses, references, file paths, and suggestions of a coding agent in the terminals, or the Text detection part of the Settings window.
- [test_levels.md](test_levels.md): the fast tests, the slow tests, and the full tests. Read it when you add or change a test command, or when you write about the tests.
