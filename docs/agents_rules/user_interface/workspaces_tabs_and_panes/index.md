This file lists the files and the subfolders of this folder, for agents and tools.

- [README.md](README.md): the overview of this folder, for people.
- [composition_bar.md](composition_bar.md): the composition bar under the focused pane: the drop of images on an open composition bar, the toggle button of the header, the plus button, the text input, the button "Send", the push-to-talk button, and the big view of the images.
- [composition_bar_drop.md](composition_bar_drop.md): the drop of image files on an open composition bar: where a drop goes, how Heidrun Code finds the composition bar under the pointer, and the layer during a drag. Read it each time that you change the drop of images.
- [file_view_pane.md](file_view_pane.md): the file view pane: a pane that shows one file, read only, how a click on a file in the File explorer sidebar section opens it, its header, its controls, and how Heidrun Code keeps it in Herdr.
- [pane_focus_history.md](pane_focus_history.md): the pane focus history, and the Back button and the Forward button of the top bar.
- [pane_move.md](pane_move.md): moving a pane with the pointer, inside its tab and to another tab: the press on the header, the four drop triangles of the destination pane, the move preview, the drop on the plus button of the tab bar that moves the pane into a new tab, the calls to Herdr, and the failures. Read it each time that you change the move of a pane, the pane header press, or the selection of a tab during a move.
- [pane_headers.md](pane_headers.md): the pane header buttons, their visibility under the pointer, Zen Mode, and the usage wheel.
- [panes.md](panes.md): the panes, the colors of Codex in a pane, and the state "Needs you".
- [tabs.md](tabs.md): the tabs.
- [workspace.md](workspace.md): the workspace.
- [workspace_commands.md](workspace_commands.md): the workspace commands, creation folders, focus events, and refreshes through Herdr.
