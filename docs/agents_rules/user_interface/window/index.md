This file lists the files and the subfolders of this folder, for agents and tools.

- [README.md](README.md): the overview of this folder, for people.
- [abbreviated_times.md](abbreviated_times.md): the circled question mark after each abbreviated time, and its title with the exact time.
- [layout.md](layout.md): the layout of the window, the rules of the layout, the text that must stay on one line, and the files.
- [statistics_window.md](statistics_window.md): the item "Statistics" of the More menu, the Statistics window, the buttons of its tabs in the title bar, and where the data of the tab "User activity" comes from.
- [statistics_charts.md](statistics_charts.md): the rules that every chart of the Statistics window follows: the chart legend, the chart information card with its arrow, the shared code, and the tests that a new chart adds. Read it each time that you add or change a chart of the Statistics window, and add the same legend, the same card, and the same tests to a new chart.
- [statistics_user_activity.md](statistics_user_activity.md): the tab "User activity" of the Statistics window: the time range, the slot length, the workspaces, the histogram of the user activity time, and its tests.
- [statistics_user_activity_stacked_bars.md](statistics_user_activity_stacked_bars.md): the stacked bars of the histogram of the tab "User activity": the parts, the colors of the workspaces, the legend, the chart information card, and its tests.
- [statistics_user_activity_vertical_axis.md](statistics_user_activity_vertical_axis.md): the vertical axis of the histogram of the tab "User activity": the top that fits the highest bar, the units, the round tops, the title with the length of the slot, and its tests.
- [statistics_person_work.md](statistics_person_work.md): the tab "Work of one person" of the Statistics window: the source (Git history or AI cost), the metric of the Git history, the unit, the person chooser, the time range, the totals, the bar chart of each day, and its tests.
- [statistics_person_work_inputs.md](statistics_person_work_inputs.md): the inputs of the tab "Work of one person": the two columns, the labels, the small buttons, the source, the metric, the person chooser, the time range, and its tests.
- [statistics_person_work_legend_filter.md](statistics_person_work_legend_filter.md): the filter of the chart legend of the tab "Work of one person": a click on a name, one filter for each chart, and the memory of the filter between two runs.
- [statistics_remembered_selections.md](statistics_remembered_selections.md): the selections of the tabs "User activity" and "Work of one person" that Heidrun Code saves as soon as they change and restores when the window opens, the options that save them, and the selections that a source hides.
- [statistics_person_work_workspace.md](statistics_person_work_workspace.md): the workspace selector of the tab "Work of one person": the buttons with a checkbox, the first choice, the sums of several workspaces, what a change reads, and its tests.
- [statistics_person_work_slots.md](statistics_person_work_slots.md): the slot length of the tab "Work of one person": the buttons of each time range, the slots (hours, days of 23 and 25 hours), the labels and the titles of the bar chart, and its tests.
- [statistics_git_history.md](statistics_git_history.md): the source "Git history" of the tab "Work of one person": what counts, and where its data comes from.
- [statistics_update_stages.md](statistics_update_stages.md): what the source "Git history" of the tab "Work of one person" shows while the database is updated: the big busy wheel, the six stages, their progress, and where the progress comes from.
- [statistics_ai_cost.md](statistics_ai_cost.md): the source "AI cost" of the tab "Work of one person": what counts, the unit (US dollars or tokens), the cost of each hour of a chat, the chats with no known price, where its data comes from, and its tests.
- [statistics_totals.md](statistics_totals.md): the lines added and deleted, and the average per day under each total, of the tab "Work of one person": what they are, how the value is written, where the calculation is, and the tests.
- [settings_guards.md](settings_guards.md): the Guards section of the Settings window, the guard window, and the button "Change this guard" of the confirmation window.
- [settings_information_cards.md](settings_information_cards.md): the rule that every option of the Settings window has a circled question mark and an information card, the layout of the card, the component `SettingsOptionHelp.vue`, the rows of a list, and the tests. Read it each time that you add or change an option of the Settings window.
- [find_new_skills_window.md](find_new_skills_window.md): the window "Find new skills": its four lines, the three sources (skills.sh, Local folder, Code hosting), the information cards, and the rows of the result.
- [settings_voice_input.md](settings_voice_input.md): the Voice input section of the Settings window, the download of a Whisper model, the push-to-talk button, the microphone permission, and the tests. Read it each time that you change the voice input.
- [settings_voice_words.md](settings_voice_words.md): the word replacement list of the voice input: the list in the Voice input section of the Settings window, the matching rules, the file `voice_words.json`, and the tests. Read it each time that you change the word replacement list or the function `replace_words`.
- [settings_notifications.md](settings_notifications.md): the rows of the Notifications section of the Settings window: the system notification, the sound, and the button "Test" of each kind of notification. Read it each time that you add a kind of notification or change the function `notify`.
- [terminal_text_detection.md](terminal_text_detection.md): the detection in the text of the terminals: the 11 detection families, the fixed precedence, the hover buttons, the switches, and the tests. Read it each time that you add or change a detection in the text of a terminal.
- [terminal_text_detection_references.md](terminal_text_detection_references.md): the forms of issues, requests, tickets, and commits that the detection accepts and refuses, and their destination. Read it each time that you change the file `lib/refs.ts`.
- [terminal_text_detection_other_families.md](terminal_text_detection_other_families.md): the forms, the refused examples, the context, and the visible result of the web addresses, file paths, shell commands, slash commands, numbered steps, agent list, and questions and choices.
- [settings_text_detection.md](settings_text_detection.md): the section "Text detection" of the Settings window: the switches, the data of the project, the patterns and the examples of each rule, and the Try a text field. Read it each time that you change the Text detection section of the Settings window, `lib/detection_patterns.ts`, or `lib/detection_catalog.ts`.
- [status_bar.md](status_bar.md): the status bar and the menu of the status item.
- [status_bar_git.md](status_bar_git.md): the Git branch section of the status bar: the branch picker, the synchronization with the upstream branch, the fetch in the background, and the counts.
- [window_state_and_start.md](window_state_and_start.md): the position and size of the window, the last state of each option, the splash screen, the notice of the missing programs Herdr and ngrok, and the goat sounds.
