This folder holds the rules of the window of Heidrun Code: its layout, its abbreviated times, its status bar, its position and size, the Statistics window with its two tabs, the Guards section of the Settings window, the information card of every option of the Settings window, the Voice input section of the Settings window with its word replacement list, and the window "Find new skills".

Start with `layout.md`, which gives the layout of the whole window. Each other file covers one part of the window.

The rules of the appearance of the window (colors, buttons, hover, contrast, icons, spacing, and scroll bars) are in the folder [web_styling](../../web_styling/index.md). Read that index before changing colors, buttons, or status displays.
