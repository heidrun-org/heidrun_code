# Rules of the Heidrun Code Dashboard

- Created: 30 October 2026
- Last updated: 30 October 2026
- Status: Maintained overview for people

- Related rules: [Glossary of Heidrun Code: Heidrun Code Dashboard](../../glossary/heidrun_code_dashboard.md)
- Related issue: [issue 968](https://github.com/heidrun-org/heidrun_code/issues/968)

This folder holds the rules of the Heidrun Code Dashboard, the view of Heidrun Code that shows every workspace, tab, coding agent, and subagent with its status. Start with `heidrun_code_dashboard_data_and_statuses.md`, which gives the data that every Heidrun Code Dashboard view shows. Then `heidrun_code_dashboard_graph_and_sidebar.md` gives the opening, the selection, the right sidebar, the counters, and the filters of the Heidrun Code Dashboard view, `heidrun_code_dashboard_radial_graph.md` gives the static radial graph, `heidrun_code_dashboard_animations.md` gives the animations, the pause, and the links of the messages, `heidrun_code_dashboard_display_modes.md` gives the modal and the separate Heidrun Code Dashboard window, and `heidrun_code_dashboard_local_network.md` gives the Heidrun Code Dashboard on a phone or a tablet of the local network. The live sources of this data are described in [Live information for the Heidrun Code Dashboard](../../../architecture/heidrun_code_dashboard_live_information.md).
