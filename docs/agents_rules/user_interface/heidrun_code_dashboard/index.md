This file lists the files of this folder, for agents and tools.

- [README.md](README.md): the overview of this folder, for people.
- [heidrun_code_dashboard_data_and_statuses.md](heidrun_code_dashboard_data_and_statuses.md): the data of the Heidrun Code Dashboard: the hierarchy, the identities, the matching of a pane to its observation, the separate facts, the visible statuses, the aggregation, the coverage, the counters, the messages, and the task texts. Read it each time that you change the folder `packages/apps/web_frontend/src/lib/heidrun_code_dashboard`, or a Heidrun Code Dashboard view that shows a status, a counter, or a message.
- [heidrun_code_dashboard_graph_and_sidebar.md](heidrun_code_dashboard_graph_and_sidebar.md): the Heidrun Code Dashboard view: the item "Dashboard" of the More menu, the modal, the subscription to the collector, the selection and the keyboard, the right sidebar, the counters, and the filters. Read it each time that you change the folder `packages/apps/web_frontend/src/components/heidrun_code_dashboard`, or the folder `packages/apps/web_frontend/src/stores/heidrun_code_dashboard`.
- [heidrun_code_dashboard_radial_graph.md](heidrun_code_dashboard_radial_graph.md): the static radial graph of the Heidrun Code Dashboard view: the sectors, the view box, Heidrun at the centre, the labels, the colors, and the outlines. Read it each time that you change the file `heidrun_code_dashboard_layout.ts` or the graph of the folder `packages/apps/web_frontend/src/components/heidrun_code_dashboard`.
- [heidrun_code_dashboard_display_modes.md](heidrun_code_dashboard_display_modes.md): the two display modes of the Heidrun Code Dashboard, the modal and the separate Heidrun Code Dashboard window: the focus, full screen, the entry `start_heidrun_code_dashboard_window.ts`, the capability of the window, the one shared collector, "Open in Heidrun Code" with its new reading of Herdr, and why the Heidrun Code Dashboard has no voice input and no Approve button. Read it each time that you change the modal, the separate Heidrun Code Dashboard window, `main.ts`, or `packages/apps/desktop_tauri/src/heidrun_code_dashboard/heidrun_code_dashboard_window.rs`.
- [heidrun_code_dashboard_animations.md](heidrun_code_dashboard_animations.md): the animations of the statuses and of Heidrun, the real transitions, the travel and the links of the messages, the pause, and the reduced motion. Read it each time that you change an animation of the Heidrun Code Dashboard graph, `heidrun_code_dashboard_transitions.ts`, or `heidrun_code_dashboard_animations.ts`.
- [heidrun_code_dashboard_local_network.md](heidrun_code_dashboard_local_network.md): the Heidrun Code Dashboard on a phone or a tablet of the local network: the section "Heidrun Code Dashboard" of the Settings window, the package `heidrun_code_dashboard_server`, the pairing key and its cookie, the checks, the read-only page with the display mode `localNetwork`, and the one shared collector. Read it each time that you change the package `packages/auxiliary/heidrun_code_dashboard_server`, `packages/apps/desktop_tauri/src/heidrun_code_dashboard/local_network.rs`, the section "Heidrun Code Dashboard" of the Settings window, or the page `/heidrun_code_dashboard`.
