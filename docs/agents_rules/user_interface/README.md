# Rules of the user interface

- Created: 13 October 2026
- Last updated: 23 October 2026
- Status: Maintained overview for people
- Related framing: [Project instructions](../../../AGENTS.md)
- Related rules: [Glossary of Heidrun Code](../glossary/index.md)
- Related issue: [issue 337](https://github.com/heidrun-org/heidrun/issues/337)

This folder holds the rules of the user interface of Heidrun Code: where each part goes, what it contains, and how it works. The appearance of the desktop window (colors, buttons, hover, contrast, icons, spacing, and scroll bars) is in the folder [web_styling](../web_styling/index.md).

Pick the subfolder of the part that you change, and read only the files that match. The words are defined in the [glossary](../glossary/index.md).
