This folder holds the rules of the Mire, the view of Heidrun Code that shows every workspace, tab, coding agent, and subagent with its status. Start with `mire_data_and_statuses.md`, which gives the data that every Mire view shows. Then `mire_graph_and_sidebar.md` gives the graph, the right sidebar, the counters, and the filters of the Mire view, `mire_animations.md` gives the animations, the pause, and the links of the messages, and `mire_display_modes.md` gives the modal and the separate Mire window. The live sources of this data are described in [Live information for the Mire](../../../architecture/mire_live_information.md).
