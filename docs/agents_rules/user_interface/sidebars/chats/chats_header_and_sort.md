# Past chats sidebar section: the header and the Chats sort dropdown menu

- Created: 13 October 2026
- Last updated: 23 October 2026
- Status: Maintained rules for agents and tools
- Related framing: [Project instructions](../../../../../AGENTS.md)
- Related rules: [Glossary of Heidrun Code](../../../glossary/index.md)

This file is a part of the rules of the user interface of Heidrun Code. The words are defined in [glossary/index.md](../../../glossary/index.md).

- The top of the Past chats sidebar section is one line with two Bootstrap radio button groups (`btn-group` with `btn-check` inputs) and the button of the Chats sort dropdown menu. At the left, one button for each coding agent that Heidrun Code supports, Claude and Codex, with its name. A button is disabled, with a title that says why, when the selected workspace has no chat of that coding agent. At the right, first the button of the Chats sort dropdown menu, then the second group with two buttons that show only an icon, with a title: the expanded view (the icon `view-stacked`), and the compact view (the icon `list`). The checked button of a group has the selected appearance of the [shared design rules](../../../web_styling/shared_design.md). The Past chats sidebar section shows no group when neither coding agent has a chat, and says so. The line of the two groups and the button of the Chats sort dropdown menu, the dynamic topic bar, and a separator line (as wide as the sidebar) form the header of the Past chats sidebar section. The header stays at the top of the Past chats sidebar section while the list scrolls under it (`position: sticky`, with the background of the sidebar).
- The compact view is the first look of the list: the rows are tight. The expanded view gives more air: each row has more space above and below it, and the lines of its summary are farther apart. The coding agent and the view that the developer chose are saved in the settings (`chatsAgent` and `chatsView`), and the next start uses them.
- The Chats sort dropdown menu sits at the right of the top line, at the left of the group of the two view buttons. Its button is a Bootstrap `btn` that shows the icon of the chosen order (`sort-down` for "Descending", `sort-up` for "Ascending"), the name of the chosen sort key (for example "Issues"), and a caret (the icon `caret-down-fill`). The icon alone shows the order, and the text alone shows the sort key. The button shows no spinning wheel: the icon never changes while a new sort waits for its answer, and the list stays on the screen until the new list arrives. A click on the button opens a Bootstrap `menu` under the button, with its right edge on the right edge of the button. The window places it (`position-fixed`, in the body of the page), so the sidebar never cuts it. The dropdown menu has two parts, each one with a `menu-header`, and a `menu-divider` between them. Each item is a `menuitemradio` with a check mark at its left (the icon `check2`, hidden with `invisible` on the items that are not chosen, so every text starts at the same place).
  1. "Sort by": "Created on" (the date of the first record that has a date, or the date of the file when no record has a date), "Last updated" (the date of the file of the chat), "Messages from you" (the number of messages that the developer typed), "Issues" (the number of issues that the chat mentions), "Pull requests" (the number of pull requests that the chat mentions), and "Files written" (the number of different files that the coding agent wrote, a file of a worktree and the same file at the root counting as one).
  2. "Order": "Ascending" (the icon `sort-up`) and "Descending" (the icon `sort-down`). The order applies to the sort key that was chosen: "Ascending" puts the smallest value first (the oldest date, or the smallest number), and "Descending" puts the largest value first (the newest date, or the largest number). Chats with the same value keep the chat with the most recent activity first.
  A click on an item chooses it, closes the dropdown menu, and reads the list again with the same number of chats. The key Escape, a click outside, and a second click on the button close the dropdown menu without a choice. The sort key and the order are saved in the settings (`chatsSortKey` and `chatsOrder`), and the next start uses them. The two choices are the same for Claude and for Codex. The items "Total comments", "Best match", and "Reactions" of the GitHub dropdown menu are not here, because a chat has no such fact. The Tauri command `chats_list` receives `sortKey` and `order`, and does the sort.
