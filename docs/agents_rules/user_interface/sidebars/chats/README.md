This folder holds the rules of the Past chats sidebar section.

Read `chats_list.md` for the list of chats, `chats_header_and_sort.md` for the buttons at the top and the sort menu, `chat_summary.md` for the lines of the summary of a chat, and `past_chats_settings_section.md` for the heading "Past chats" of the section "Sidebars" of the Settings window. The folder `information_cards` covers the information cards, and the folder `dynamic_topics` covers the dynamic topics.
