This file lists the files and the subfolders of this folder, for agents and tools.

- [README.md](README.md): the overview of this folder, for people.
- [sidebars.md](sidebars.md): the sidebars and the clipboard.
- [source_control.md](source_control.md): the Source control sidebar section.
- [code_hosting.md](code_hosting.md): the Code hosting sidebar section: the header buttons, the icon, the two lists, the rows, the information card, and the cache.
- [code_hosting_search.md](code_hosting_search.md): the search line of each list of the Code hosting sidebar section, the search language of GitHub and of GitLab, and the labels of the information card of a row.
- [code_hosting_merge.md](code_hosting_merge.md): the approval state of a pull request or a merge request, the merge bar of its information card and of the issue preview window, the merge window, and the permanent branches. Read it each time that you change the merge.
- [code_hosting_saved_searches.md](code_hosting_saved_searches.md): the saved searches of the Code hosting sidebar section, their two levels (user and workspace), the information card tooltip of their buttons, and the windows "Save this search" and "Edit the saved search". Read it each time that you change a saved search.
- [files.md](files.md): the File explorer sidebar section.
- [files_folders_read_from_disk.md](files_folders_read_from_disk.md): the folders of the File explorer sidebar section whose content comes from the disk: a folder that Git ignores, and a symbolic link to a folder.
- [file_search.md](file_search.md): the Search in files sidebar section: the text box, the options "Match case" and "Regular expression", the results grouped by file, and the click on a line that opens the file at that line.
- [launchers.md](launchers.md): the Launchers sidebar section: the two levels of a launcher (user and workspace), where each level is kept, the order of the cards, the windows "Create a custom launcher" and "Edit a custom launcher", and the folder of a launcher of the user level. Read it each time that you change a launcher.
- [needs_you_workspaces.md](needs_you_workspaces.md): the list of workspaces at the bottom of the Needs you sidebar section, and the heading "Needs you" of the section "Sidebars" of the Settings window.
- [user_activity.md](user_activity.md): the User activity sidebar section: the detection of the activity of the developer, the user activity records, and the view.
- [chats/](chats/index.md): the Past chats sidebar section.
