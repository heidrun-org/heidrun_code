- Last updated: 23 October 2026
- Status: Maintained overview for people

- Related issue: [issue 337](https://github.com/heidrun-org/heidrun/issues/337), [issue 617](https://github.com/heidrun-org/heidrun/issues/617), [issue 799](https://github.com/heidrun-org/heidrun/issues/799)

This folder holds the rules that every coding agent follows when it works on Heidrun Code.

Read the glossary first, because it defines the words that the other files use. The glossary is the folder `glossary`, split by topic: read only the files that match the part that you change. Then read only the files of the folder `user_interface` that match the part that you change. Read the index of the folder `web_styling` before you change a color, a button, a hover, a space, or an icon: it holds all the rules of the appearance of the web page. Read [data_layer_access.md](data_layer_access.md) each time that you change the Past chats sidebar section, the Statistics window, or a package of the data layer: it says where the data of these two parts must come from. The file `AGENTS.md` at the root of the repository lists every file of this folder.
