## 0. Introduction

### 0.1. Scope

File explorer sidebar section and Source control sidebar section.

## 1. Definitions

### 1.1. File explorer sidebar section

The File explorer sidebar section shows the files and folders of the selected [Workspace](workspaces_tabs_and_panes.md#11-workspace) and lets you open files in a [File view pane](workspaces_tabs_and_panes.md#14-file-view-pane).

Approval: [decision 000007](../decisions/2026/11/decision-000007-file-explorer-sidebar-section.md).

### 1.2. Source control sidebar section

The Source control sidebar section shows changes in the selected [Workspace](workspaces_tabs_and_panes.md#11-workspace)’s Git repository and provides controls for working with those changes.

Approval: [decision 000008](../decisions/2026/11/decision-000008-source-control-sidebar-section.md).

## 2. Transferred definitions

The following entries come from the glossary transfer. Individual approval links identify the decisions already recorded.

### 2.1. Left sidebar

The sidebar to the left of the Viewport.

[Transferred source](../proposals/glossary_migration_sources/sidebars.md#source-line-14).

### 2.2. Right sidebar

The sidebar to the right of the Viewport.

[Transferred source](../proposals/glossary_migration_sources/sidebars.md#source-line-18).

### 2.3. Sidebar section

One section shown within a sidebar.

[Transferred source](../proposals/glossary_migration_sources/sidebars.md#source-line-22).

### 2.4. Clipboard sidebar section

The sidebar section that lists pinned notes and images from the Chat in the selected Pane.

[Transferred source](../proposals/glossary_migration_sources/sidebars.md#source-line-26).

### 2.5. Launchers sidebar section

The sidebar section for the Launchers available in the selected Workspace.

[Transferred source](../proposals/glossary_migration_sources/sidebars.md#source-line-30).

### 2.6. Launcher

A named command with an optional starting folder that the developer can run in its own Tab.

[Transferred source](../proposals/glossary_migration_sources/sidebars.md#source-line-34).

### 2.7. Code hosting sidebar section

The sidebar section for issues, pull requests, and merge requests on the hosting service for the selected Workspace’s repository.

[Transferred source](../proposals/glossary_migration_sources/sidebars.md#source-line-42).

### 2.8. Search in files sidebar section

The sidebar section for searching the contents of files in the selected Workspace’s Git repository.

[Transferred source](../proposals/glossary_migration_sources/sidebars.md#source-line-50).

### 2.9. Sidebar icon bar

The row of icons along the outer edge of a sidebar for opening its Sidebar sections.

[Transferred source](../proposals/glossary_migration_sources/sidebars.md#source-line-54).
