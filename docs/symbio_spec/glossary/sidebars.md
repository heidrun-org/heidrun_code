## 0. Introduction

### 0.1. Scope

File explorer sidebar section and Source control sidebar section.

## 1. Definitions

### 1.1. File explorer sidebar section

The File explorer sidebar section shows the files and folders of the selected [Workspace](workspaces_tabs_and_panes.md#11-workspace) and lets you open files in a [File view pane](workspaces_tabs_and_panes.md#14-file-view-pane).

Approval: [decision 000007](../decisions/2026/11/decision-000007-file-explorer-sidebar-section.md).

### 1.2. Source control sidebar section

The Source control sidebar section shows changes in the selected [Workspace](workspaces_tabs_and_panes.md#11-workspace)’s Git repository and provides controls for working with those changes.

Approval: [decision 000008](../decisions/2026/11/decision-000008-source-control-sidebar-section.md).
