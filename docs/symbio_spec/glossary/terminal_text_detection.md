## 1. Definitions

### 1.1. Input image previews

Previews of images attached to chat messages, shown from attachment labels in a terminal.

[Transferred source](../proposals/glossary_migration_sources/terminal_text_detection.md#source-line-14).

### 1.2. Terminal reference

A shorthand number or full web address in a terminal that refers to an issue, GitHub pull request, or GitLab merge request.

[Transferred source](../proposals/glossary_migration_sources/terminal_text_detection.md#source-line-18).
