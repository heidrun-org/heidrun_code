## 1. Definitions

### 1.1. Search line

The row of search controls for one list in the Code hosting sidebar section.

[Transferred source](../proposals/glossary_migration_sources/code_hosting.md#source-line-12).

### 1.2. Search field

The text field for entering a search in a Search line.

[Transferred source](../proposals/glossary_migration_sources/code_hosting.md#source-line-16).

### 1.3. Saved search

A named search saved for one list in the Code hosting sidebar section.

[Transferred source](../proposals/glossary_migration_sources/code_hosting.md#source-line-20).

### 1.4. Level of a saved search

Whether a Saved search is available at the user level or the workspace level.

[Transferred source](../proposals/glossary_migration_sources/code_hosting.md#source-line-24).

### 1.5. Approval state

The review status of a pull request or merge request.

[Transferred source](../proposals/glossary_migration_sources/code_hosting.md#source-line-28).

### 1.6. Merge method

The way a hosting service combines the changes of a pull request or merge request with the destination branch.

[Transferred source](../proposals/glossary_migration_sources/code_hosting.md#source-line-32).

### 1.7. Merge bar

The row of approval information and merge controls in a pull request or merge request Information card.

[Transferred source](../proposals/glossary_migration_sources/code_hosting.md#source-line-36).

### 1.8. Merge window

The window that shows merge details and lets the developer confirm a merge.

[Transferred source](../proposals/glossary_migration_sources/code_hosting.md#source-line-40).

### 1.9. Permanent branch

A branch that Heidrun Code preserves when it merges a pull request or merge request.

[Transferred source](../proposals/glossary_migration_sources/code_hosting.md#source-line-44).
