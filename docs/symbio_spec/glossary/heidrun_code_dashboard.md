## 1. Definitions

### 1.1. Heidrun Code Dashboard

The view of Workspaces, Tabs, coding agents, and Subagents with their statuses.

[Transferred source](../proposals/glossary_migration_sources/heidrun_code_dashboard.md#source-line-14).

### 1.2. Separate Heidrun Code Dashboard window

A separate window that displays the Heidrun Code Dashboard.

[Transferred source](../proposals/glossary_migration_sources/heidrun_code_dashboard.md#source-line-20).

### 1.3. Heidrun Code Dashboard on the local network

The read-only Heidrun Code Dashboard available to devices on the same local network.

[Transferred source](../proposals/glossary_migration_sources/heidrun_code_dashboard.md#source-line-24).

### 1.4. Heidrun Code Dashboard model

The shared data that the Heidrun Code Dashboard displays.

[Transferred source](../proposals/glossary_migration_sources/heidrun_code_dashboard.md#source-line-32).

### 1.5. Subagent in the Heidrun Code Dashboard

A running Claude Code Subagent or a Codex child Chat.

[Transferred source](../proposals/glossary_migration_sources/heidrun_code_dashboard.md#source-line-36).

Review note: Keep the running dashboard concept distinct from the configured Subagent.

### 1.6. Live observation

Status, messages, and requests reported by a coding agent or its Subagents while they run.

[Transferred source](../proposals/glossary_migration_sources/heidrun_code_dashboard.md#source-line-40).

### 1.7. Visible status

The status the Heidrun Code Dashboard displays for a coding agent or Subagent.

[Transferred source](../proposals/glossary_migration_sources/heidrun_code_dashboard.md#source-line-44).

### 1.8. Freshness

How current and well matched a Live observation for a coding agent or Subagent is.

[Transferred source](../proposals/glossary_migration_sources/heidrun_code_dashboard.md#source-line-48).

### 1.9. Coverage

The count of Heidrun Code Dashboard items, including the counts for unknown, stale, unmatched, and unobserved items.

[Transferred source](../proposals/glossary_migration_sources/heidrun_code_dashboard.md#source-line-52).

Review note: Distinguish the product term from Symbiospec Coverage.

### 1.10. Pending attention

A question or approval request awaiting an answer.

[Transferred source](../proposals/glossary_migration_sources/heidrun_code_dashboard.md#source-line-56).
