## 1. Definitions

### 1.1. Status bar

The row at the bottom of the window that holds Status bar sections.

[Transferred source](../proposals/glossary_migration_sources/status_bar.md#source-line-14).

### 1.2. Status bar section

One part of the Status bar that presents one kind of information.

[Transferred source](../proposals/glossary_migration_sources/status_bar.md#source-line-18).

### 1.3. Unspecified Claude quota

The status that indicates Heidrun Code has no quota figures for Claude Code.

[Transferred source](../proposals/glossary_migration_sources/status_bar.md#source-line-22).

### 1.4. Information card tooltip

The card with explanatory text that appears after a delay when a control has pointer or keyboard focus.

[Transferred source](../proposals/glossary_migration_sources/status_bar.md#source-line-30).

### 1.5. Workspace status bar section

The Status bar section with information and actions for Workspaces.

[Transferred source](../proposals/glossary_migration_sources/status_bar.md#source-line-34).
