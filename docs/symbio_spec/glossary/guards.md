## 0. Introduction

The meaning of Guard action.

## 1. Definitions

### 1.1. Guard action

What Heidrun Code does when a Guard matches a command. Heidrun Code asks for confirmation or forbids the command.

Approval: [decision 000001](../decisions/2026/11/decision-000001-action-terminology.md).

## 2. Transferred definitions

The following entries come from the glossary transfer. Individual approval links identify the decisions already recorded.

### 2.1. Guard

A check Heidrun Code makes before sending a command to a terminal.

[Transferred source](../proposals/glossary_migration_sources/guards.md#source-line-12).

### 2.2. Built-in guard

A Guard supplied by Heidrun Code.

[Transferred source](../proposals/glossary_migration_sources/guards.md#source-line-16).

Review note: Check the scope of the label Hardcoded against the official term Built-in guard.

### 2.3. Project guard

A Guard defined by a project.

[Transferred source](../proposals/glossary_migration_sources/guards.md#source-line-20).

### 2.4. Line

One condition that a Project guard can use to match a command.

[Transferred source](../proposals/glossary_migration_sources/guards.md#source-line-28).

### 2.5. Guard window

The window for viewing a Built-in guard or adding or editing a Project guard.

[Transferred source](../proposals/glossary_migration_sources/guards.md#source-line-32).

### 2.6. Confirmation window

The window Heidrun Code opens when a Guard interrupts a command.

[Transferred source](../proposals/glossary_migration_sources/guards.md#source-line-36).

### 2.7. Guards section

The section of the Settings window for managing Project guards and Built-in guards.

[Transferred source](../proposals/glossary_migration_sources/guards.md#source-line-40).
