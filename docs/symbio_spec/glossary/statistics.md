## 0. Introduction

### 0.1. Scope

User activity action, User activity time, Slot, and Average per day.

## 1. Definitions

### 1.1. User activity action

A keyboard or mouse event counted by User activity.

Approval: [decision 000001](../decisions/2026/11/decision-000001-action-terminology.md).

### 1.2. User activity time

The time that the developer is active in front of Heidrun Code, counted for one Workspace. Agent time measures how long a coding agent works on a request.

Approval: [User activity time definition](https://github.com/heidrun-org/heidrun_code/issues/440) and [Agent time context](https://github.com/heidrun-org/heidrun_code/issues/438).

### 1.3. Slot

A Slot is a time interval represented by one bar in a chart.

Approval: [decision 000003](../decisions/2026/11/decision-000003-slot.md).

### 1.4. Average per day

Average per day is the total divided by the number of days in the selected time range, including days with no activity.

Approval: [decision 000005](../decisions/2026/11/decision-000005-average-per-day.md).
