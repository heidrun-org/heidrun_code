## 1. Definitions

### 1.1. Voice input

The feature that changes the developer’s speech into text.

[Transferred source](../proposals/glossary_migration_sources/voice_input.md#source-line-14).

### 1.2. Push-to-talk button

The Composition bar control for recording speech with Voice input.

[Transferred source](../proposals/glossary_migration_sources/voice_input.md#source-line-18).

### 1.3. Level bars

The bars that show the volume of speech during recording and indicate the state of transcription.

[Transferred source](../proposals/glossary_migration_sources/voice_input.md#source-line-22).

### 1.4. Waiting for transcription

The state after recording ends while another recording is being transcribed.

[Transferred source](../proposals/glossary_migration_sources/voice_input.md#source-line-26).

### 1.5. Recording icon

The indicator of a Pane’s recording or transcription state on Tabs and Workspaces.

[Transferred source](../proposals/glossary_migration_sources/voice_input.md#source-line-30).

### 1.6. Whisper model

The model that Heidrun Code uses to change speech into text.

[Transferred source](../proposals/glossary_migration_sources/voice_input.md#source-line-34).

Review note: Check the stated model count before carrying it into Behaviour.

### 1.7. Voice input section

The section of the Settings window for Voice input.

[Transferred source](../proposals/glossary_migration_sources/voice_input.md#source-line-38).

### 1.8. Word replacement list

The list of text replacements that Heidrun Code applies to transcription.

[Transferred source](../proposals/glossary_migration_sources/voice_input.md#source-line-42).

### 1.9. Whisper writes

The text that one entry in the Word replacement list matches.

[Transferred source](../proposals/glossary_migration_sources/voice_input.md#source-line-46).

### 1.10. Heidrun Code writes instead

The replacement text in one entry in the Word replacement list.

[Transferred source](../proposals/glossary_migration_sources/voice_input.md#source-line-50).
