## 1. Definitions

### 1.1. Information card

An Information card shows details and may offer actions for an item in Heidrun Code.

Approval: [decision 000002](../decisions/2026/11/decision-000002-information-card.md).

### 1.2. Text detection

The section of the Settings window for web links, [Information cards](#11-information-card) for terminal references, and Input image previews.

Approval: [decision 000006](../decisions/2026/11/decision-000006-text-detection.md).
