## 1. Definitions

### 1.1. Cool down

The period with no counted input after which the developer is no longer active.

[Transferred source](../proposals/glossary_migration_sources/user_activity.md#source-line-22).

### 1.2. Active period

An interval during which Heidrun Code counts User activity for one Workspace.

[Transferred source](../proposals/glossary_migration_sources/user_activity.md#source-line-26).

### 1.3. User activity record

A saved description of an Active period.

[Transferred source](../proposals/glossary_migration_sources/user_activity.md#source-line-30).

### 1.4. User activity sidebar section

The sidebar section that shows today’s User activity records.

[Transferred source](../proposals/glossary_migration_sources/user_activity.md#source-line-34).

### 1.5. Statistics window

The window that presents Heidrun Code statistics.

[Transferred source](../proposals/glossary_migration_sources/user_activity.md#source-line-40).

### 1.6. User activity tab

The tab of the Statistics window that shows User activity time.

[Transferred source](../proposals/glossary_migration_sources/user_activity.md#source-line-44).

### 1.7. Histogram of the user activity time

The chart that shows User activity time by Slot and Workspace.

[Transferred source](../proposals/glossary_migration_sources/user_activity.md#source-line-48).
