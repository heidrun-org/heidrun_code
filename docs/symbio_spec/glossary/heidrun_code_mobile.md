## 1. Definitions

### 1.1. Heidrun Code Mobile

The mobile website for controlling coding agents running on the computer.

[Transferred source](../proposals/glossary_migration_sources/heidrun_code_mobile.md#source-line-12).

### 1.2. Mobile website

The website opened on the phone to use Heidrun Code Mobile.

[Transferred source](../proposals/glossary_migration_sources/heidrun_code_mobile.md#source-line-16).

### 1.3. Pairing key

The secret that allows the phone to make requests to the mobile server.

[Transferred source](../proposals/glossary_migration_sources/heidrun_code_mobile.md#source-line-24).

### 1.4. Bottom bar

The row of navigation buttons at the bottom of the Mobile website.

[Transferred source](../proposals/glossary_migration_sources/heidrun_code_mobile.md#source-line-28).

### 1.5. Plain terminal on the phone

A Pane shown on the phone with a terminal that has no coding agent.

[Transferred source](../proposals/glossary_migration_sources/heidrun_code_mobile.md#source-line-32).

### 1.6. Macro button

The control that opens the available Macros for a Pane on the phone.

[Transferred source](../proposals/glossary_migration_sources/heidrun_code_mobile.md#source-line-36).

### 1.7. Microphone button

The control for speech recognition on the phone.

[Transferred source](../proposals/glossary_migration_sources/heidrun_code_mobile.md#source-line-40).

Review note: Keep distinct from the desktop push-to-talk button.
