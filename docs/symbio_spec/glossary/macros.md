## 0. Introduction

### 0.1. Scope

Definitions of Macro, User macro, and Project macro.

## 1. Definitions

### 1.1. Macro

Reusable text that Heidrun Code can insert into a [Pane](workspaces_tabs_and_panes.md#13-pane).

Approval: [decision 000009](../decisions/2026/11/decision-000009-macro-terms.md).

### 1.2. User macro

A [Macro](#11-macro) available to the developer across projects on the same computer.

Approval: [decision 000009](../decisions/2026/11/decision-000009-macro-terms.md).

### 1.3. Project macro

A [Macro](#11-macro) shared with the developers of one project.

Approval: [decision 000009](../decisions/2026/11/decision-000009-macro-terms.md).
