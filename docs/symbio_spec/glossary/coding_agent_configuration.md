## 1. Definitions

### 1.1. Coding agent configuration

The Memory files, Subagents, and Skills that configure a coding agent.

[Transferred source](../proposals/glossary_migration_sources/coding_agent_configuration.md#source-line-14).

### 1.2. Memory file

A file containing stored information used by a coding agent.

[Transferred source](../proposals/glossary_migration_sources/coding_agent_configuration.md#source-line-18).

Review note: Check supported sources in the data layer. The source claim about Codex could refer to collection support or to Codex itself.

### 1.3. Subagent

In Coding agent configuration, a configured coding agent that the main coding agent can start with its own instructions.

[Transferred source](../proposals/glossary_migration_sources/coding_agent_configuration.md#source-line-22).

Review note: Distinguish configured Subagent from a running Subagent in the Heidrun Code Dashboard.

### 1.4. Skill

A folder with a `SKILL.md` that tells a coding agent how to perform a task.

[Transferred source](../proposals/glossary_migration_sources/coding_agent_configuration.md#source-line-26).

### 1.5. Removed configuration item

A previously recorded configuration item whose file is no longer found during synchronization.

[Transferred source](../proposals/glossary_migration_sources/coding_agent_configuration.md#source-line-30).
