## 1. Definitions

### 1.1. Heidrun Organization

The project that includes Heidrun Code and Heidrun Notebook.

[Transferred source](../proposals/glossary_migration_sources/heidrun_names.md#source-line-12).

### 1.2. Heidrun Code

The application for working with coding agents and seeing which one needs the developer.

[Transferred source](../proposals/glossary_migration_sources/heidrun_names.md#source-line-16).

### 1.3. Heidrun Notebook

The application for project management and note taking.

[Transferred source](../proposals/glossary_migration_sources/heidrun_names.md#source-line-20).

### 1.4. Official name

The name used for an application in text for people.

[Transferred source](../proposals/glossary_migration_sources/heidrun_names.md#source-line-24).

Review note: Keep the product naming rule consistent with AGENTS.md.

### 1.5. Identifier

The name used to identify an application in a repository, package, folder, or application bundle.

[Transferred source](../proposals/glossary_migration_sources/heidrun_names.md#source-line-28).

### 1.6. Former name

A name the project used before a rename.

[Transferred source](../proposals/glossary_migration_sources/heidrun_names.md#source-line-32).

### 1.7. Persisted name

A name kept for compatibility with existing files, sessions, or settings.

[Transferred source](../proposals/glossary_migration_sources/heidrun_names.md#source-line-45).
