## 1. Definitions

### 1.1. Dynamic topic

A short label Heidrun Code computes from a Chat to identify a subject.

[Transferred source](../proposals/glossary_migration_sources/dynamic_topics.md#source-line-12).

### 1.2. Raw dynamic topic

A Dynamic topic as first extracted from a Chat.

[Transferred source](../proposals/glossary_migration_sources/dynamic_topics.md#source-line-16).

### 1.3. Clustered dynamic topic

The shared name for Raw dynamic topics with close meanings.

[Transferred source](../proposals/glossary_migration_sources/dynamic_topics.md#source-line-20).

### 1.4. Translation table

The association between each Raw dynamic topic and its Clustered dynamic topic.

[Transferred source](../proposals/glossary_migration_sources/dynamic_topics.md#source-line-24).

### 1.5. Dynamic topic source information

The information from a Chat that Heidrun Code uses to compute its Dynamic topics.

[Transferred source](../proposals/glossary_migration_sources/dynamic_topics.md#source-line-28).

### 1.6. Dynamic topic extraction

The method Heidrun Code uses to compute Dynamic topics from the Dynamic topic source information.

[Transferred source](../proposals/glossary_migration_sources/dynamic_topics.md#source-line-32).

### 1.7. Dynamic topic bar

The row of controls for choosing Dynamic topics in the Past chats sidebar section.

[Transferred source](../proposals/glossary_migration_sources/dynamic_topics.md#source-line-36).
