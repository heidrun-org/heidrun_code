### Source line 9

This folder holds the glossary of Heidrun Code: one short definition for each word that the project uses for a part of the application. Use these words, and no other word, in the code, in the documents, and in the conversations. One word means one thing, and one thing has one word.

The glossary is split by topic into small files. Read only the files that match the part that you change. The file `index.md` lists them.
