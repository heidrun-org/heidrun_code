## 0. Introduction

### 0.1. Purpose

Record the approved scope and the parts of Symbiospec that own related rules.

## 1. Decision

A Pane is an area within a Tab that holds content. A Tab can contain several Panes. A Pane can show a terminal, including one running a coding agent, a file, or changes to a file. Each Pane has a Pane header with a title, information about the Pane, and controls. Keep File view pane and Diff pane as separate terms tied to Pane.

## 2. Reason

The developer described Pane as the area within a Tab, gave examples of its content, and identified the title and controls of the Pane header.

## 3. Effect on earlier decisions

No earlier Symbiospec decision is replaced.

## 4. Unresolved conditions

The appearance of the active Pane and the placement of Pane header controls belong in User Interface.
