## 0. Introduction

### 0.1. Purpose

Record the approved scope and the parts of Symbiospec that own related rules.

## 1. Decision

Use Guard action for what Heidrun Code does when a Guard matches and User activity action for a keyboard or mouse event counted by User activity. Keep the existing labels in Heidrun Code.

## 2. Reason

The same word describes a matching Guard result and a counted input event.

## 3. Effect on earlier decisions

No earlier Symbiospec decision is replaced.

## 4. Unresolved conditions

The conditions under which an input event counts and the consequences of each Guard action belong in Behaviour.
