## 0. Introduction

### 0.1. Purpose

Record the approved scope and the parts of Symbiospec that own related rules.

## 1. Decision

A Macro is reusable text that Heidrun Code can insert into a Pane. A User macro is a Macro available to the developer across projects on the same computer. A Project macro is a Macro shared with the developers of one project.

## 2. Reason

The three terms give a common definition and identify where each kind of Macro is available.

## 3. Effect on earlier decisions

No earlier Symbiospec decision is replaced.

## 4. Unresolved conditions

Click and Shift-click belong in Behaviour. The menu and controls belong in User Interface, and storage details belong in technical documentation.
