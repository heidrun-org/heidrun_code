# Marketing of Heidrun Code

- Created: 9 October 2026
- Last updated: 13 October 2026
- Status: Maintained overview for people
- Related framing: [Project instructions](../../AGENTS.md)

These rules apply to the public website (`packages/auxiliary/website_public`), to the README, to release notes, and to every text that presents Heidrun Code to the public.

This folder also holds the method to record marketing videos. Read the file that matches your question:

- To write or change the title, the motto, or the description, read [identity_texts.md](identity_texts.md).
- To write the name of the application or of the goat, or to explain the origin of the name, read [name_of_heidrun.md](name_of_heidrun.md).
- To write a joke, read [jokes.md](jokes.md), then [mythology_and_developers.md](mythology_and_developers.md) for the six words and the link to the developers.
- To use the splash image or another key image, read [images.md](images.md).
- To record a marketing video, read [recording_videos.md](recording_videos.md).
