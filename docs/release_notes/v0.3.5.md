## What is new in 0.3.5

### Name of the application

- Heidrun is now called Heidrun Code, with the new application identifier `dev.heidrun-org.heidrun-code`.
- The website has the new address `heidrun_code`, and the command line tools and skills of the former names are removed.

### Chats and dynamic topics

- The Chats sidebar section shows a topic timeline: one row for each dynamic topic, and one dot for each chat over time.
- The dynamic topics are more specific, and they cost less, because Heidrun Code asks the coding agent with a light model and less often.
- The dynamic topic bar has visible arrows, and you can scroll it with the trackpad.
- The information card of an issue has a button to start a chat about the issue.

### Clipboard sidebar section

- The Clipboard sidebar section shows the image behind each text `[Image #N]` of a chat of Claude Code or of Codex.
- The image of a text `[Image #N]` appears when the pointer is over the text.

### Files

- The file view pane has the shortcut Command-P, editing, Search in files, and a way to ask the coding agent about the selected lines.
- The file view pane shows the new content when the file changes on the disk.
- The Markdown preview uses the full width by default, has the switch Wrap at 80 columns, a correct background, and internal links that work.
- The HTML preview works.
- A read-only diff pane shows the changes of a file.
- The context menu of the File explorer has the item "Chat about this file".
- The File explorer shows a symbolic link to a folder as a folder.
- The Files window and the large Git window are removed.

### Voice input

- The voice input works across tabs and workspaces, with a queue of transcriptions, a notification, and a recording icon.
- The word replacement list changes the words that Whisper writes wrongly.

### Panes and tabs

- Drop a dragged pane on the plus button of the tab bar to move the pane into a new tab.
- When the selected tab closes, the most recent pane of another tab gets the focus.
- At the start, the composition bar opens for the coding agents that Herdr kept running.

### Notifications and launchers

- Each kind of notification has a system notification switch, a sound, and a test button.
- A custom launcher has a level: user or workspace.

### Code hosting

- The Code hosting sidebar section keeps its lists until a refresh, and shows the age of the kept list.
- When the GitHub or GitLab rate limit is exceeded, a message gives the local reset time.
- A message appears when a refresh of the Code hosting sidebar section fails.

### Statistics

- The Statistics window shows the stages and the progress of the database update.
- The AI cost is correct when several workspaces work in the same hour.

### Skills and logs

- The window Find new skills lists every skill of a folder and compares each one with the installed skill.
- The application log records the calls to `gh` and `glab`, Herdr, Git, the mobile server, the voice input, the start of the application, and the download of the Whisper model.

### Documentation

- The user documentation has new pages with real screenshots.

The complete list of changes is in the file `CHANGELOG.md`.

The disk image is not signed, not notarized, and built only for the architecture of the machine that builds it.
