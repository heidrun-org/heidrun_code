## What is new in 0.4.0

### Heidrun Code Dashboard

- See your workspaces, coding agents, and subagents together in a graph, with status counters, filters, and details about observed activity.
- Open Heidrun Code Dashboard in a separate window or full screen, and double-click a workspace or coding agent to show the corresponding workspace or pane in the main window.
- Show Heidrun Code Dashboard on a phone or tablet on your local network by scanning a pairing QR code.
- Touch the page once to keep the phone or tablet screen on while Heidrun Code Dashboard is displayed.
- Resize the details sidebar, read full workspace names, and follow animated activity indicators with support for reduced motion.

### Code hosting and coding agents

- Merge GitHub pull requests and GitLab merge requests from Heidrun Code, with approval details, merge methods, reasons that prevent merging, and protection for permanent branches.
- Coding agents launched from issue and pull request chats are tracked in Heidrun Code Dashboard.
- Filter Past chats with independent Claude and Codex checkboxes, and see both kinds of chats together with their coding agent icons.

### Files

- Open a file outside the workspace from its path in the terminal, choose Heidrun Code or the default application, and remember your choice.
- Reveal files in Finder or open files with Visual Studio Code from the File explorer context menu.
- Open a file on GitHub or GitLab at the current commit or on the current branch, including files inside submodules.

### Macros

- Save multiline Markdown macro descriptions while keeping the macro menu compact with only the first description line.
- Browse separate Project macro and User macro groups, view macro details, and move macros between project and user locations.
- Read guidance for the Title, Description, Location, and Content fields in macro dialogs.

### Tabs, skills, and appearance

- Press and hold the plus button of the tab bar to choose Terminal or an enabled coding agent for a new tab.
- Compare skills with clearer added and removed line colors and highlights for changed words.
- Read menu items more clearly when the pointer is over them, and see improved spacing between the title and motto on the splash screen.

### Command line tools

- Use `heidrun_code_ctrl` to list, create, rename, focus, and close tabs and panes, split panes, send text and keys, read terminal output, and wait for text.

The complete list of changes is in the file `CHANGELOG.md`.

The disk image is not signed, not notarized, and built only for the architecture of the machine that builds it.
