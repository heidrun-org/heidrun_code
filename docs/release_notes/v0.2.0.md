## What is new in 0.2.0

### Name and start

- The application is now called Heidrun in place of Herdr Desk, and Heidrun migrates your existing data.
- A splash screen and an image in the About window are new.
- The project configuration is in the file `.heidrun/config.json`.

### Panes and sidebar

- The Panes list has a menu and a close button on each row, in place of the horizontal pane tabs.
- One plus icon creates a new pane, Heidrun remembers the values that you chose, and Enter confirms.
- A template menu in the pane header replaces the bottom row.
- A row of the Panes list shows the pane status when the pointer is not over the row, and the buttons when it is.
- Reorder the rows of the Panes list with drag and drop.
- Only one pane rename field is shown, in the place where the rename started.
- The workspace rows are simpler, with a menu Rename and a close button.
- The plus buttons of the sidebar are identical.

### Status bar

- The status bar shows the agent status counters and the Git indicator, each with a hover card, and the cards stay open.
- A star after the branch name shows that the working folder has uncommitted changes.
- The status bar has a Codex quota label with a hover card that shows the pace, and the Settings window has a General section.

### Appearance and language

- Heidrun has a light theme and a dark theme, and the Codex input area is readable in the light mode.
- The terminal pane has soft border colors in the light theme, and the scroll bar of the terminal panel is no longer white.
- Heidrun uses Bootstrap Icons everywhere, and every clickable element has a title.
- The user interface is in English or in French, and the labels of the application menu follow the language of the system.
- The Refresh button shows a spinner while it refreshes.
- A modal dialog replaces the timed close confirmation.

### Website and project

- Heidrun has a public website, an MIT license, and the community files.

The complete list of changes is in the file `CHANGELOG.md`.

The disk image is not signed, not notarized, and built only for the architecture of the machine that builds it.
