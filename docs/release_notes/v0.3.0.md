## What is new in 0.3.0

### Heidrun Mobile

- Use Heidrun from a phone, through an ngrok tunnel with a fixed address and a QR code.
- Use the launchers, the microphone, the macros, the terminals, and the notifications from the phone.
- The screens of Heidrun Mobile show the Heidrun icon in the header.
- Heidrun stops the ngrok tunnel that an earlier Heidrun left running, and a button Stop the old ngrok also stops the tunnel of a second Heidrun.

### Voice input

- Speak with a push-to-talk button, and a local Whisper model changes your voice into text.
- While Heidrun changes your voice into text, a green sine wave crosses the flat level bars.
- Cancel the voice input from the composition bar.
- Heidrun tells you when another pane uses the voice input.

### Composition bar

- The composition bar stays open after you press Send.
- Each pane keeps its own composition bar and its own draft.
- Drop images on an open composition bar.
- A Settings option sets whether the composition bar opens when a coding agent starts.

### Panes and workspaces

- Move a pane by drag and drop, inside its tab and to another tab.
- Zen Mode helps you to work with focus, and the Zen button is visible in every pane.
- The buttons of the header of a pane appear only while the pointer is over the pane.
- The window New pane is gone: a new pane or a new tab opens a terminal tab at once.
- The shortcut Command-W follows corrected rules to close a tab.
- Browse the Git worktrees of a repository, and open a workspace from one of them.
- The card of the workspace selector has a link to the repository.
- The search button of the top bar shows the name of the selected workspace.
- Resize the list of workspaces of the Needs you sidebar section with a line to drag.

### Macros

- The macro menu has the actions Edit, Delete, and Create.
- The macro menu is wider, with small buttons Edit and Delete on the title line.

### Files

- A file that you click in the File explorer opens in a read-only file view pane, with the front matter in a card.
- The File explorer browses the Git submodules.

### Statistics

- The Statistics window remembers your selections, and the vertical axis of the tab "User activity" fits its data.
- The inputs are clearer, the window can use the full screen, and the filter of the legend is remembered.
- The tab "User activity" has the choice "Last month" in place of "Last hour", and it shows only the open workspaces.
- The tab "Work of one person" shows the lines added and deleted with the average for each day, or the commits, or the pull requests.
- The tab "Work of one person" shows the AI cost in US dollars or in tokens, for one workspace or for several workspaces.
- The AI cost includes the compressed files of Codex, the files of the subagents and the workflows of Claude Code, and the chats of worktrees and sub-folders.

### Settings

- The Settings window has eight sections.
- Every option has a circled question mark that opens an information card.
- New: the section Text detection, the section Guards, and a goat sound.
- Heidrun keeps your saved options when it updates.

### Code hosting and Source control

- Each list of the Code hosting sidebar section has a search line, with help beside the title of the list.
- A card of the Code hosting sidebar section can open in full size, and its labels are buttons.
- A saved search has two levels, User and Workspace, and an information card explains each level.
- A button in the information card copies the web address of an issue or a pull request.
- The Source control sidebar section is polished, and its discard buttons have distinct icons.

### Skills and command line tools

- The command line tool `heidrun_data` answers questions about the history of a repository, the past chats, the memory files, the skills, and your activity.
- The command line tool `heidrun_ctrl` changes the macros, the launchers, and the workspaces of a running Heidrun.
- Heidrun installs both tools, with their skills, for your coding agents.
- The window Find new skills has three sources, reads folders on GitLab, and has information cards.

### Coding agents and terminals

- The coding agent Antigravity is supported everywhere.
- Heidrun enables the coding agents that it finds installed.
- Codex works in the light theme, and Heidrun no longer types a long `printf` line in a pane before it starts Codex.
- The Past chats sidebar section hides the review chats of Codex.
- Heidrun keeps your coding agents running after you quit.
- Heidrun reads the `PATH` of your login shell, so the installed Heidrun finds `gh`.
- A copy of wrapped text in a terminal keeps the command lines whole.
- A copy of the selected text of a terminal works when Herdr cannot give the original text.
- A shell command that a coding agent wrote on several lines runs as one whole line.

### Appearance and status indicators

- A black bar at the right edge of the window is gone.
- The status colors and the Working indicators are the same everywhere, and you can acknowledge a Finished result in all the status indicators of the desktop.
- An information card is centered on its circled question mark, and the information card of the usage wheel stays inside the window.
- The usage wheel hides when the pointer is not over the pane.
- The icon buttons have correct borders, and the selected color theme has a better contrast.
- The flying smileys keep a fixed size.

### Installation and the application

- Install Heidrun with one command: the script `scripts/install.sh` installs the latest release.
- The website has a new homepage and new pages behind the homepage, and a link to the website shows a preview card.
- The installed Heidrun has a new application identifier, `dev.heidrun-org.heidrun`.
- Heidrun needs macOS 11.0 or later.
- At the start, Heidrun checks that the programs Herdr and ngrok are installed.

The complete list of changes is in the file `CHANGELOG.md`.

The disk image is not signed, not notarized, and built only for the architecture of the machine that builds it.
