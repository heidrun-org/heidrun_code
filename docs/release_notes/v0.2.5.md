## What is new in 0.2.5

### Sidebar

- The sidebar has three new sections: Chats, Source control, and Files.
- The Source control sidebar section replaces the Git sidebar section and works like the one of Visual Studio Code.
- The Chats sidebar section shows dynamic topics, extracted with keywords or with a language model, and it has a sort menu.
- The sidebar section "To handle" is now called "Needs you".
- Each sidebar section has an icon, and each sidebar collapses to an icon bar or hides completely.
- The tab Actions is now called Scripts, with the sections Custom Scripts and Existing Scripts, and a plus button opens a window to create a custom script.
- The Pane sidebar section of the right sidebar is gone.

### Status bar and menu bar

- The status bar has a workspace selector that opens its list in an information card.
- The status bar has a Git branch picker and a button that synchronizes with the upstream branch.
- The status bar shows only the quotas of the coding agents that are switched on.
- The status bar section with the number of agents that are blocked, working, or done is gone.
- The menu bar item on macOS shows the state of each agent and the quota of Claude and Codex, with colored status dots, flat discs, and quota badges.
- A setting shows or hides the menu bar item, and the item is narrow enough that the camera notch does not hide it.
- The Working status in the menu bar item has the color violet.

### Windows and Settings

- The Settings window has a section Agents, where the whole row of an agent is its switch.
- The window Agents information has the section All agents.
- A menu with three vertical dots in the top bar is new, the skills have two windows, and Heidrun manages the files `SKILL.md` with the API of skills.sh.
- Heidrun links an installed skill for an agent that you switch on later.
- New settings: the default command of a new tab, and questions before a tab, a workspace, or a note is closed.
- Heidrun saves the last state of each option.
- The prompt templates are now called macros.
- The information cards open with a click, and the cards of the usage of Claude and Codex are wider.

### Window and panes

- Heidrun remembers the position and the size of the window, and the selected workspace, and restores them at the next start.
- The tab bar is on top of the viewport, with a larger workspace button at its left end and an icon on each tab, and the whole tab is clickable.
- The panes touch each other and the border of the viewport, with one thin line and square corners, and the selected pane is easier to identify.
- Resize the height of a pane, and resize in two directions from a corner.
- A shell pane is named after its folder or its running command.
- A pinned pane keeps the same width in every tab, and a pinned note shows in its own workspace.
- The font size zoom applies to the whole window.
- The shortcut Command+T starts the default command of a new tab.
- Drop an image onto a terminal to paste it.
- Reorder tabs, workspaces, and notes with the mouse.
- The terminal no longer blinks or shows shifted lines while you resize the window.
- Heidrun uses its own named Herdr session and stops it when you quit.

### Appearance

- The colors follow Visual Studio Code Dark Modern and Light Modern, with three background levels.
- A notification uses the theme colors in the light mode.
- An empty tab shows a baby goat, the name of Heidrun, and a joke with a firework, in light colors in the light theme.
- The application icon is a simple goat that is readable at 16 pixels, and the web page has it as its favicon.
- The About window, the splash screen, and the empty tab have goat sounds.
- The splash screen has a larger title and a motto written along an arc, and no black window appears before it.
- The command line option `--no-splash-screen` starts Heidrun without the splash screen.

### Website

- The public website has the favicon of Heidrun.

The complete list of changes is in the file `CHANGELOG.md`.

The disk image is not signed, not notarized, and built only for the architecture of the machine that builds it.
