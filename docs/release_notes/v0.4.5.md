## What is new in 0.4.5

### Application updates

- Check for, download, and install new Heidrun Code releases from within the application on Apple silicon.

### Source Control, File explorer, and Code hosting

- Open files and diffs from Source Control and files from File explorer in focused tabs.
- See when a commit is in progress and get refreshed Source Control status when it finishes.
- See Code hosting refresh when the Git remote changes.
- See a pull request or merge request's approval state in its preview.

### Voice input

- Set a maximum recording duration and choose when to receive a warning before recording stops.
- Keep the microphone visible while Heidrun Code transcribes a recording.

### Heidrun Code Dashboard and Workspace cards

- Fold the Heidrun Code Dashboard sidebar and see the notice about missing Codex activity only when a Codex pane is present.
- See more Workspace card content with wider cards and compact copy buttons.

### Launchers, macros, and skills

- Reorder launchers at each level by dragging them or pressing Option and an arrow key.
- Scroll long macro dialogs within the window.
- Compare all installed skill files with their source.

The complete list of changes is in the file `CHANGELOG.md`.

The disk image is not signed, not notarized, and built only for the architecture of the machine that builds it.
