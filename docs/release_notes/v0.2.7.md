## What is new in 0.2.7

### Sidebar sections

- The Code hosting sidebar section shows the issues and the pull requests of GitHub or GitLab, with saved searches.
- The User activity sidebar section detects your activity.
- The Launchers sidebar section replaces the Scripts sidebar section, imports the scripts of every `package.json` of the repository, and can run a command line in the current work folder.
- The window Create a custom script is rebuilt.
- The Past chats sidebar section replaces the Chats sidebar section. It shows the tokens, the estimated cost, and the worktree names of each chat, and the Settings window has an option to switch off the dynamic topics.
- The File explorer sidebar section replaces the Files sidebar section. It has a context menu on the row of each file and each folder, an option to show the files that Git ignores, and it shows a folder that Git ignores only once.
- The Clipboard sidebar section replaces the Notes sidebar section, and its choice "All workspaces" is a switch.
- The Needs you sidebar section shows the list of workspaces at its bottom, and its cards use the theme colors.
- The left sidebar and the right sidebar have no fixed maximum width.

### Statistics

- The new Statistics window, in the More menu, has two tabs.
- The tab "User activity" shows a histogram of the user activity time, stacked by workspace, and you choose the slot length and the workspaces.
- The tab "Work of one person" shows the Git history or the AI cost of one person for each day.
- Every chart has a legend and an information card.

### Panes and tabs

- The top bar has a Back button and a Forward button to go through the panes that had the focus.
- Each pane shows its context window as a usage wheel that opens an information card.
- A tab switch keeps the terminals of the opened tabs alive, so the terminal does not blink.
- A new pane, a new tab, and a new workspace start the default command of a new tab.
- The last tab of a workspace cannot be closed, and Heidrun shows an error notification.
- Heidrun shows a clear message when another client holds a terminal, and each worktree has its own Herdr session.
- The controls of the large Git window are in its title bar, and the name Reading is now Preview.

### Coding agents

- The coding agent Antigravity is in the list of coding agents.
- Heidrun reads the models and the efforts of each coding agent from its own tool.
- The window Find new skills installs a skill from the web address of a skill folder on GitHub.

### Settings and the application

- The Settings window is rewritten with Bootstrap components.
- Heidrun fetches the remote repository in the background, and the Settings window has the delay between two fetches.
- The window About Heidrun shows the date and the time of the build after the version.
- Each abbreviated time, such as "Just now", has a circled question mark that shows the exact time.
- The desktop application has a window with a Three.js demo.

### Website

- The homepage of the public website has the Flux Lines background.
- The About page of the website has the video that explains how to pronounce Heiðrún.

The complete list of changes is in the file `CHANGELOG.md`.

The disk image is not signed, not notarized, and built only for the architecture of the machine that builds it.
