To install Heidrun Code on a Mac with Apple silicon, run this command in a terminal. macOS opens Heidrun Code with no message.

```sh
curl -fsSL https://raw.githubusercontent.com/heidrun-org/heidrun_code/main/scripts/install.sh | sh
```

You can also download the disk image (`.dmg` file) below, open it, and drag Heidrun Code to your Applications folder.
