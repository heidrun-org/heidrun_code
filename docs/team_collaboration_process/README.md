# Team collaboration process

- Created: 12 October 2026
- Last updated: 13 October 2026
- Status: Maintained overview for people
- Related framing: [Project instructions](../../AGENTS.md)

This folder describes how the people who work on Heidrun Code work together. Each document in this folder explains one part of the process.

- [team_workflow.md](team_workflow.md): the way several developers work on one repository when coding agents write much of the code, with a full test before every merge.
- [agreement_about_product.md](agreement_about_product.md): the way collaborators agree on product decisions without a meeting, with a GitHub issue that each collaborator answers in a comment.
- [asynchronous_communication.md](asynchronous_communication.md): the way collaborators send requests to each other without a meeting, with a GitHub issue that a coding agent writes and a coding agent helps to read.
