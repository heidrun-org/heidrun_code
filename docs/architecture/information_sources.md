# The information sources

- Created: 11 October 2026
- Last updated: 13 October 2026
- Status: Maintained description of the information sources
- Related framing: [Project instructions](../../AGENTS.md)

Heidrun Code assumes that the project has a Git repository, and a Git hosting service such as GitHub or GitLab. The conversations around the project live in these places. This gives Heidrun Code much information. The source code is the key, and it is not the only source.

## The three sources

1. **The source code and its history.** This source is the Git repository on the local computer, with its folder `.git`.
2. **The Git hosting service.** This source is GitHub or GitLab. It holds the issues, the pull requests, and the collaboration between the people of the project.
3. **The chat logs of the coding agents.** This source shows how the local developer builds the code. Heidrun Code reads the chat logs of Claude Code, of Codex, and of the other coding agents.

## Why three sources

- The Git repository says what the code is, and how the code changed.
- The Git hosting service says what the people of the project asked for, and what they discussed.
- The chat logs say how the code was built on the local computer, step by step, with the coding agents.
