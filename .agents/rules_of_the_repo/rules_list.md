# The Rules of the Repo

| Skill | When it applies | Rule type | Configuration |
|---|---|---|---|
| [context_md_system](../skills/context_md_system/SKILL.md) | Edit or add files, create source folders, change folder responsibilities or exported interfaces, or maintain `CONTEXT.md` | Living rule without human approval | none |
| [docs_folder_system](../skills/docs_folder_system/SKILL.md) | Add, change, rename, move, or delete files or folders in `docs` | Static rule | [config.md](config/docs_folder_system/config.md) |
| [docs_folder_agents_rules_system](../skills/docs_folder_agents_rules_system/SKILL.md) | Change code, agent rules, or glossary terms | Living rule without human approval | [config.md](config/docs_folder_agents_rules_system/config.md) |
| [keep-a-changelog-workflow](../skills/keep-a-changelog-workflow/SKILL.md) | Change `CHANGELOG.md` | Static rule | none |
| [repo_folders_constraints](../skills/repo_folders_constraints/SKILL.md) | Add files, add imports or dependencies between packages, create, move, rename, or delete folders or packages, change required technologies, or change content governed by a folder workflow | Living rule with human approval | [config.md](config/repo_folders_constraints/config.md) |
| [symbio_spec](../skills/symbio_spec/SKILL.md) | Change product behavior or edit the product specification | Living rule with human approval | [config.md](config/symbio_spec/config.md) |
