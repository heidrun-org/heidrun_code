# Repo Folders Constraints

These tables record existing folder responsibilities, package boundaries, and workflows. The **May import** column lists dependencies between repository packages, including workspace dependencies from submodules. Build outputs and command-line calls are described under **Workflow**. For submodule internals, follow each submodule's own repository instructions.

The other-folder rows cover descendants unless a more specific row applies. Read the applicable `CONTEXT.md` files for local details. Changes to these tables require human approval through The Rules of the Repo.
