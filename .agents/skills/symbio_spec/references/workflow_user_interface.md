# Propose user interface structure

The optional `symbio_spec_to_ux` draft proposes objects, relationships, calls to action, attributes, screens, and navigation from approved concepts and behaviour. Use the companion's installed instructions when available. If the companion is absent, see the [draft in the source repository](https://github.com/jeromeetienne/coding_agent_plugins/blob/main/skills/symbio_spec_to_ux/README.md) and the [companion installation guidance](../README.md#related-skills-and-guides). The draft is awaiting a real-project trial, and its scope ends at proposals for human review.

Expose missing product decisions and preserve existing approvals. Use the core [Update Symbiospec as the software changes](workflow_update.md) workflow to maintain affected User Interface specifications and record authorized decisions.
