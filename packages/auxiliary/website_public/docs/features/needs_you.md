# The Needs you sidebar section

You run several coding agents at the same time. Each coding agent stops from time to time: it asks for a permission, it asks a question, or it has finished and waits for your review. Without help, you find these coding agents only when you look at their terminals one by one.

## What Heidrun Code does

The Needs you sidebar section, in the right sidebar, holds one card for each coding agent that needs you:

- A coding agent that is blocked: it waits for a decision, for example the permission to run a command.
- A coding agent that asks a question.
- A coding agent that has finished.

The blocked coding agents come first. The button of the Needs you sidebar section shows the number of cards, and the number turns red when a coding agent is blocked.

![The Needs you sidebar section with the card of a blocked coding agent that asks which title to choose, and under it the list of the two workspaces with their Git branch.](/screenshots/features/needs_you.png){width=300}

## What you do with a card

- Click the card to go to the pane of the coding agent.
- Answer a blocked coding agent from its card, without going to its pane.
- Pin the pane of the coding agent, so that the pane stays visible.
- Hide the card. A hidden card comes back at the next change of the coding agent.

A finished coding agent leaves the Needs you sidebar section after a delay that you set in the Settings window.

## The list of workspaces

Under the cards, the Needs you sidebar section lists all your workspaces. Each row shows a status dot with the color of the coding agents of the workspace, the name of the workspace, and its Git branch.

- Click a row to go to the workspace.
- Drag a row to change the order of the workspaces.
- Switch off "Show the workspaces" in the section "Needs you" of the Settings window to hide the list.

## Even when the window is hidden

The status item in the macOS menu bar shows the same states: blocked, finished, and working. Click the status item to see the coding agents of each state, or to open Heidrun Code.

*In Valhalla, nobody waits in line for mead. In Heidrun Code, no coding agent waits in a terminal that you forgot.*
