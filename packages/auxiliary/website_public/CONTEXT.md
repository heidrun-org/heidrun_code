# Directory Context: `/packages/auxiliary/website_public`

## Purpose
The public website of Heidrun Code: a homepage and the user documentation, built with VitePress and published on GitHub Pages with the script `ghpage:deploy`.

## Key Exports & Entry Points
- `docs/`: the Markdown source of the website. `docs/index.md` is the homepage. `docs/documentation/` holds the documentation pages.
- `docs/.vitepress/config.ts`: the VitePress configuration (title, description, navigation, sidebar, `base`). It also writes the hero of the homepage from `data/identity.json`.
- `docs/public/favicon.svg`: the favicon of every page, linked by the `head` option of `docs/.vitepress/config.ts`.
- `docs/.vitepress/link_preview_cards.ts`: the class `LinkPreviewCards`, which builds the Open Graph tags, the X card tags, the theme color, and the canonical address. `docs/.vitepress/config.ts` puts the shared tags in the option `head`, and the page tags (title, description, address) in the hook `transformHead`.
- `docs/public/heidrun_link_preview_card.png`: the card image of every page, 1200 by 630 pixels.
- `docs/.vitepress/theme/home/`: the sections of the homepage under the hero, and their texts — see its own CONTEXT.md.
- `docs/features/`: the eight feature pages of issue 517, listed in the menu "Features" of `docs/.vitepress/config.ts` and linked from the homepage.
- `docs/public/screenshots/`: the real captures of the Heidrun Code window on the homepage, and in `features/` the captures of the feature pages.
- `docs/.vitepress/theme/youtube_video.vue`: the component `YoutubeVideo`, registered in `docs/.vitepress/theme/index.ts`. A page shows a YouTube video with `<YoutubeVideo video-id="..." title="..." />`.
- `docs/.vitepress/theme/home_flux_lines.vue`: the component `HomeFluxLines`, put in the slot `layout-top` of the layout by `docs/.vitepress/theme/index.ts`. It shows the Flux Lines background on the pages with the layout `home` only, in golden lines on the dark theme and in dark golden ink on the light theme.
- `docs/.vitepress/theme/flux_lines.vue`: the component `FluxLines`, a canvas that the class `FluxLinesRenderer` (`flux_lines_renderer.ts`) draws into with WebGL2. The shaders are in `flux_lines_shaders.ts`, the types in `flux_lines_types.ts`.
- `tests/`: the Vitest tests of the website (configuration, pages, shortcuts page, identity texts, the macOS quarantine message in the developer documents and its absence from the release text, splash image, YouTube video, favicon, Flux Lines background, sections and texts of the homepage, link preview cards, complete build).
- Command to run this folder: `pnpm --filter website_public dev`
- Command to test this folder: `pnpm --filter website_public test`

## Rules
- The `base` option in `docs/.vitepress/config.ts` equals the GitHub Pages path of the repository (`/heidrun_code/`).
- Nothing in this folder imports from another package of the workspace. The one shared file is `data/identity.json`, which is not a package.
- The title, the description, and the hero of the homepage come from `data/identity.json`. No page holds a hand-written copy.
- The brand color of the website is the mead color of the application (`#f2a93b`), set in `docs/.vitepress/theme/custom.css`. The headings of the homepage use the font Familjen Grotesk, loaded by the `head` option of `docs/.vitepress/config.ts`.

- `docs/public/favicon.svg` is a copy of `data/images/heidrun_favicon.svg`, the favicon of the application, and the test `tests/favicon.test.ts` fails when the two files differ.
- The page `docs/documentation/shortcuts.md` is generated by `pnpm docs:shortcuts`: its text has no raw angle bracket, because VitePress reads `<agent>` as a Vue tag and the build fails.

- Every page has the same card image, an absolute address under `https://heidrun-org.github.io/heidrun_code/`, and its own `og:title`, `og:description`, `og:url`, and canonical address. The title and the description of the homepage come from `data/identity.json`, and every feature page and the page `docs/about.md` has a one-sentence `description` in its frontmatter.
- The card image is a PNG file of 1200 by 630 pixels and less than 300000 bytes, with its title and goat inside the central 1000 pixels. The test `tests/link_preview_cards.test.ts` fails when one of these is wrong.
- The Flux Lines background keeps the lines faint (an opacity of 0.7 or less) and puts a layer of the page color over the hero text, so the text keeps a contrast ratio of at least 4.5 to 1 on both themes. The component draws nothing when the browser has no WebGL2.
- `flux_lines_renderer.ts` and `flux_lines_shaders.ts` are a port of the Flux Lines background of React Bits (MIT + Commons Clause, Copyright (c) 2026 David Haz), and each file keeps the copyright notice.
