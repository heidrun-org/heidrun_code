# Directory Context: `/packages/apps/web_frontend/src/dev`

## Purpose
Code that only runs in the development server, so that the web frontend shows its connected screens in a plain browser, without the Tauri window and without a running Herdr server.

## Key Exports & Entry Points
- `install_tauri_mock.ts`: imported first by `src/main.ts`; calls `TauriMock.install()`.
- `tauri_mock.ts`: `TauriMock`, a minimal replacement for the Tauri bridge. It answers a short list of Tauri commands and rejects every other command.
- `tauri_mock_fixture.ts`: `TauriMockFixture`, the fake Herdr session (two workspaces, three tabs, four panes, every agent status). It keeps the share of the one split between the two panes of the first tab, so that the request `layout.set_split_ratio` moves the line between them. It also holds the fake conversations of Claude and Codex that the Tauri command `chats_list` returns, sorted by the `sortKey` and the `order` that the command receives. It also builds the answers of `gh issue view` and `gh pr view` for the Tauri command `forge_cli_cached` (the issue 123 fails on purpose), and the answers of `gh issue list` and `gh pr list` for the same Tauri command `forge_cli_cached` and for the Tauri command `forge_cli_cached_with_source` (never a failure), which keep only the items that match the words `author:`, `label:`, and `no:label` of the flag `--search`. It also keeps a fake translation table of the clustered dynamic topics, and answers the Tauri command `coding_agent_ask` with a fake coding agent that groups the new labels by their first four letters, and that gives each chat of the method "Language model" the first two long words of its title. It also builds the fake active periods of the last 30 days that the Tauri command `user_activity_records_in_range` returns, for the histogram of the Statistics window, in its three time ranges and its slot lengths. The periods belong to three workspace folders, so that the histogram has workspaces to choose. It also builds the fake commits, pull requests, and issues of two people in the last 30 days that the Tauri command `person_work_in_range` returns, for the tab "Work of one person" of the Statistics window. It also builds the fake stored token usage of Claude Code and of Codex in the last 30 days, with the tokens and the estimated cost of each coding agent in each hour, one day with no known price, that the Tauri command `ai_cost_in_range` returns, for the source "AI cost" of the same tab. A fake workspace has no hour until the Tauri command `ai_cost_synchronize` imports its history. It also keeps the configuration of one fake project, which the Tauri commands `project_load` and `project_save` read and write, so that the Guards section of the Settings window can add, change, and remove a guard. The Tauri commands `chats_synchronize`, `chat_references_synchronize`, `user_activity_synchronize`, `person_work_synchronize`, and `ai_cost_synchronize` answer at once, because the fake computer has no source to copy, and the read commands `chats_list`, `chat_references_find`, `user_activity_records_in_range`, `person_work_in_range`, and `ai_cost_in_range` return the fake stored data. The Tauri command `chat_images_find` returns a chat with no image. The Mire commands answer with no observation and an unavailable shared Codex server (`mire_subscribe`), no observer mod (`mire_claude_observer_mod_path`), and no prepared Codex chat (`codex_prepare_chat`), because the fake computer has no live source.
- `design_review.ts` and `design_review.vue`: standalone shared design review page at `/design_review.html`, using the real application stylesheet without a Tauri mock.
- Command to run this folder: `pnpm dev:web`, then open `http://localhost:1420`.

## Rules
- Nothing in the production build contains this folder: `TauriMock.install()` returns at once when `import.meta.env.DEV` is false.
- `TauriMock.install()` does nothing when a real Tauri bridge already exists, so the Tauri window never uses the mock, and nothing on the path `/mire`, the Mire page of a device of the local network, which must never show a fake answer.
- Nothing outside this folder imports from this folder, except the first import line of `src/main.ts`.
- A Tauri command that the mock does not list is rejected with an error. Add a command to the mock only when a screen needs it to render.
- The terminal panel stays without a mock: the commands `pty_spawn`, `pty_write`, `pty_resize`, and `pty_kill` are rejected.
